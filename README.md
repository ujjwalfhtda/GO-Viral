# PromptVerse V1

A PromptHero-inspired AI prompt discovery web app.

## Included
- Prompt search
- Model/category filters
- Prompt cards
- Prompt detail modal
- Copy-to-clipboard
- Favorites in current session
- Responsive dark UI

## Run
1. Install Node.js 18+.
2. `npm install`
3. `npm run dev`
4. Open `http://localhost:3000`
